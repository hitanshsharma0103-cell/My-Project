Project Title: Python Number Guessing Game

Description

What is this project?
This project is a simple, interactive command-line game written in Python. The computer selects a random secret number between 1 and 100, and the user's task is to guess this number. The game provides hints ("Bigger number please" or "Lesser number please") after each attempt and tracks the total number of turns the user takes to find the correct number.

Why was it built?
This script serves as an excellent, straightforward example of fundamental Python programming for beginners. It effectively demonstrates key concepts like random number generation, user input handling, and essential control flow structures (while loop and if/elif/else logic) in a practical, fun application.

Features

Random Selection: The computer randomly selects a secret integer between 1 and 100.

Interactive Hints: Provides real-time feedback after each guess, telling the user if the correct number is "Bigger" or "Lesser."

Turn Counter: Tracks and displays the final total number of turns required to win the game.
